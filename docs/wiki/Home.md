# TabPlayer Wiki

TabPlayer is an independent tablature-to-MIDI performance engine. It imports tablature, builds a timed performance
timeline, shows the score and drives external instruments through MIDI. It is not a guitar synthesiser or a Luthier edition.

**Status:** bootstrap, early development. ASCII tab import, MIDI playback timeline, a VST3/Standalone shell and a tab view
exist. DAW compatibility and downloadable installers are not established.
